# Updating

1. Download the new release zip from the
   [Releases page](https://github.com/xinjalin/Local-AI-Live-Translate/releases/latest) and replace
   the old folder with it — or run `git pull` in a clone.
2. Reload the extension: open `chrome://extensions` and press the reload arrow on
   **Local AI Live Translate**.

Your settings, profiles, display configs and API keys are kept by the browser, not in the folder, so
they carry over.

!!! warning "Edited prompt templates"
    If you've edited the templates in the `templates/` folder (or added your own), copy them across
    before replacing the folder.

What changed in each version: [release notes](https://github.com/xinjalin/Local-AI-Live-Translate/releases).
