# Local AI Live Translate — docs and model benchmarks

Source of the documentation site for [Local AI Live Translate](https://github.com/xinjalin/Local-AI-Live-Translate):
guides, and the translation model dashboard.

**Site: <https://xinjalin.github.io/Local-AI-Live-Translate-docs/>**

## Layout

| Path | Contents |
|---|---|
| `docs/` | The site's pages (Markdown), images, and the dashboard (`docs/models/index.md`, `docs/assets/models.js`) |
| `docs/data/benchmarks.json` | The dashboard's data — generated by `bench/build_benchmarks.py`, don't edit by hand |
| `bench/` | The translation benchmark: `translation_bench.py`, the test sentences, raw results and `models.json` |
| `mkdocs.yml` | Site configuration and navigation |
| `.github/workflows/deploy.yml` | Builds the site and publishes it on GitHub Pages on every push to `main` |

## Editing the site

Pages are Markdown in `docs/`. To preview locally:

```bash
pip install -r requirements.txt
mkdocs serve
```

then open <http://127.0.0.1:8000>. (Stop the Local AI Live Translate server first, or use
`mkdocs serve -a 127.0.0.1:8001` — both use port 8000.)
